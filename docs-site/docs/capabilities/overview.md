# 能力总览

`aihub/` 是 Java 大模型客户端。你可以只使用这一层完成模型调用；Spring Boot 项目再加 starter。

| 目标 | 文档 |
| --- | --- |
| 发 Chat / Responses | [模型接入](/docs/capabilities/models/overview) |
| 图像、音频、视频、音乐、Realtime | [图像生成](/docs/capabilities/media/image-generation) |
| 请求里带 tools | [工具协议](/docs/capabilities/tools/overview) |
| 服务工厂 | [服务入口](/docs/capabilities/service-entry) |

不在本模块：Skill 资源、MCP、会话记忆持久化、RAG / 向量库、Agent。
