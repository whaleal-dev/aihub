# 功能地图

本仓库只提供客户端能力。

| 能力 | 状态 | 模块 | 入口 |
| --- | --- | --- | --- |
| Java 首次调用 | stable | `aihub` | [Java 快速开始](/docs/getting-started/quickstart-java) |
| Spring Boot | stable | `aihub-spring-boot-starter` | [Spring Boot 快速开始](/docs/getting-started/quickstart-spring-boot) |
| Chat / Completions | stable | `aihub` | [Chat](/docs/capabilities/models/chat) |
| Responses / Messages | stable | `aihub` | [Responses](/docs/capabilities/models/responses) |
| 流式 SSE | stable | `aihub` | [Streaming](/docs/capabilities/models/streaming) |
| 图像 / 音频 / 视频 / 音乐 / Realtime | stable | `aihub` | [媒体生成](/docs/capabilities/media/image-generation) |
| `tools` 协议字段 | stable | `aihub` | [工具协议](/docs/capabilities/tools/overview) |
| 注解编 JSON Schema | stable | `aihub` | [注解式工具](/docs/capabilities/tools/annotation-based-tools) |

不在本仓库：RAG、MCP、Agent、工作流、Coding CLI。
